# Computational-Simulations-II

This repository contains implementations of various numerical methods mainly in Python to simulate physical systems. The code is organized into different folders, each corresponding to a specific given class or seminar. The main focus is on the simulation of physical phenomena, including quantum and statistical models, growth processes, diffusion processes, and other related topics.

It corresponds to the course "Computational Simulations II" at the São Paulo State University (UNESP), Brazil, taught by Prof. Dr. Luis Antonio Cabral. The course is part of the Physics undergraduate program and is offered in the second semester of 2026.

Every folder contains a README.md file that provides an overview of the implemented methods, instructions for running the code, and examples of the generated results. The code is designed to be modular and easily extensible, allowing students to explore different physical systems and numerical techniques.

The codes and documentation are still being developed and added with time, so please check back for updates. The repository is intended for educational purposes and can be used as a reference for students and researchers interested in computational physics ;)
